# Changelog

All notable changes to the TwinPix Workspace project will be documented in this file.

## [v1.0] - Enterprise Agency Platform
- **Added**: Comprehensive Project Management hierarchy (Client -> Project -> Campaign -> Task).
- **Added**: Deep API integration for webhooks and background jobs.
- **Added**: Enterprise RBAC (Role-Based Access Control) for secure data segregation.
- **Added**: Global Search functionality.
- **Changed**: Completely overhauled database schema to support massive scaling.

## [v0.9] - Project Workspace
- **Added**: Dedicated "My Tasks" view for individual team members.
- **Added**: Advanced filtering and sorting on the Task board.
- **Added**: Centralized file storage linked to specific entities.

## [v0.8] - Notifications
- **Added**: In-app real-time bell notifications.
- **Added**: Automated Email delivery using Resend.
- **Added**: WhatsApp webhook integration for critical alerts.

## [v0.7] - AI Assistant
- **Added**: ChatGPT integration for the Copilot feature.
- **Added**: AI-generated Creator Insights (Strengths/Weaknesses).
- **Added**: Brand Match Analysis scoring.

## [v0.5] - Premium UI
- **Changed**: Migrated entirely to a modern light theme UI.
- **Added**: Integrated `shadcn/ui` components for consistency.
- **Added**: Responsive navigation and optimized table layouts.

## [v0.1] - Initial CRM
- **Added**: Basic Influencer and Client database models.
- **Added**: Simple NextAuth authentication.
- **Added**: Rudimentary tracking of influencer metrics.
